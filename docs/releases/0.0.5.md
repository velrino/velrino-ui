# Velrino UI 0.0.5

Add a reusable binary Switch with accessible interaction and optional square sci-fi presentation.

## Switch

- Import `Switch` and `SwitchProps` from `@velrino/ui/switch`, or use the root export. Load the existing `@velrino/ui/styles.css` once.
- Supply controlled `checked`/`onCheckedChange` or uncontrolled `defaultChecked`. The callback retains Base UI change details, including cancellation.
- Associate a visible label or accessible name. The native button supports Tab and Space/Enter, forwarded refs and descriptions without submitting a surrounding form. The companion input supports `name`, `value`, `uncheckedValue`, external `form` ownership and `required` validation.
- Disabled settings cannot activate or receive keyboard focus. Read-only settings remain focusable without changing. Applications own persistence and asynchronous behavior.
- Standard appearance stays rounded. `appearance="sci-fi"` inherits from UIProvider or can be set per component, using a square track and subtly chamfered thumb. Semantic tokens, a 44-pixel target, an unclipped focus outline, high-contrast styling and reduced-motion behavior remain available.

## Gallery and compatibility

Live Switch examples appear under Inputs in English and Brazilian Portuguese. The gallery retains its 17 section IDs and keeps setting state while language or appearance changes. Custom `DesignSystemCopy` dictionaries need the new `inputs.switches` fields.

The component uses the existing pinned Base UI dependency. React/React DOM remain peers supporting 19.1 through 19.x; no Next.js, Tailwind scanning or new dependency is introduced. Existing component exports and CSS paths remain available.

## Release validation

The release gate includes formatting, lint, package/gallery types, behavioral tests and the production package build. Focused Switch checks cover controlled updates, label/ref behavior, keyboard activation, disabled/read-only states, form values, required validation and cancellation. Packed-consumer checks verify granular imports, declarations, SSR and bundled CSS with pnpm/React 19.1 and npm/React 19.3. Desktop/mobile gallery checks cover appearance, keyboard focus, touch target size, reduced motion and localization. These checks do not establish physical-device performance; CI completion and publication are verified separately.

Install the versioned `velrino-ui-0.0.5.tgz` archive and verify its adjacent SHA-256 checksum. The fixed `velrino-ui.tgz` alias contains the same bytes. See [v0.0.5 adoption](https://github.com/velrino/velrino-ui/blob/v0.0.5/docs/adoption.md) for installation. Distribution remains through GitHub Releases, with no npm registry publication.
