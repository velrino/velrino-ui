# Velrino UI 0.0.8

Combobox accepts an optional `renderOption(option)` callback for visual content such as thumbnails, swatches and icons. Keep a descriptive plain-text `label` on every option: it remains the filtering source, selected input text and accessible option name. Mark decorative previews with `aria-hidden` or an empty image alt. Existing options and default rendering remain compatible.

```tsx
<Combobox
  options={items}
  toggleLabel="Show items"
  emptyMessage="No items found"
  renderOption={(option) => (
    <>
      <img src={previews[option.value]} alt="" />
      <span>{option.label}</span>
    </>
  )}
/>
```

Custom content inherits the existing theme, mobile interaction targets, disabled handling, keyboard selection and modal focus containment. The gallery demonstrates the same API in both languages. Distribute the tested archive through GitHub Releases; no npm publication is requested.
