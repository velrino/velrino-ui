# Velrino UI 0.0.1

First GitHub distribution of the portable React package.

- Twelve component families, typed props and independently bundled runtime/gallery CSS.
- Standard `Panel` and `Dialog` surfaces, with explicit sci-fi framing through `appearance` or `UIProvider`.
- Accessible dialog/sheet/menu/tab interactions, progress/cancellation and grapheme-aware animated text.
- An adapter-based gallery in English and Portuguese, with live examples and desktop/mobile browser checks.
- React and React DOM as peers, tested with React 19.1 and 19.3 using pnpm and npm.

Install the attached tarball; its SHA-256 checksum is attached alongside it. No npm registry publication or registry credentials are required. See [adoption](../adoption.md) for application integration.
