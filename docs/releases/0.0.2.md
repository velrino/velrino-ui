# Velrino UI 0.0.2

- Add a host navigation slot and searchable section index; the example uses a single menu with Go to, Language, Theme and Surfaces, opening in Go to.
- Correct standalone Dialog/Tabs box sizing and mobile tab layout to prevent unintended modal overflow.

- Present one color per mobile row and center Button/Sheet examples one per line.
- Add live HEX/RGBA values beside semantic color tokens, including translucent color-mix results and host theme updates.
- Organize the standalone preview behind a fixed navbar and centered settings dialog with theme, surface and language tabs, consistent option widths and local English/Portuguese flag icons.
- Use the preferred HackUniverse palette for the Cyan preview and simplify theme names to Cyan, Purple and Red.

Install the compiled tarball and verify the attached SHA-256 checksum. See [adoption](https://github.com/velrino/velrino-ui/blob/v0.0.2/docs/adoption.md).
