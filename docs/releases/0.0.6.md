# Velrino UI 0.0.6

Add reusable, mobile-first hierarchical navigation and a lighter documentation interface.

## SidebarNavigation

- Support up to five levels with application-neutral labels, optional icons/badges, independent destinations and disclosure buttons.
- Choose single sibling expansion, independent multiple expansion, or permanently all-expanded presentation.
- Use controlled or uncontrolled expansion, a current destination, disabled subtrees and consumer router-link rendering. Routing, storage, permissions and counts belong to the app.
- Keep native links/buttons, visible focus, hidden-descendant focus recovery and 44px interaction targets. Invalid depth, duplicate IDs and cyclic input fail explicitly.
- Import from the package root or `@velrino/ui/sidebar-navigation`; use the existing bundled stylesheet and optional sci-fi appearance provider.

## Connected step progress

`StepNavigation` adds opt-in `variant="progress"`: numbered circles above labels and a connecting line that animates toward the controlled current step in either direction. The default variant stays unchanged. Keyboard behavior, disabled states, mobile labels and reduced motion remain supported. Long sequences scroll internally.

## Gallery and themes

The gallery adds an English/Portuguese Sidebar navigation section with five levels and all three modes. Layout starts as a single mobile column and expands on larger screens. Custom dictionaries need `sidebar` and `sections.sidebar` fields.

Reusable light tokens use `data-vui-color-scheme="light"`. The gallery has a dark/light icon toggle, compact toolbar, restrained spacing and icon-only menu/theme controls. The original system font family is preserved.

## Validation and distribution

Behavior checks cover expansion, ancestry, controlled state, navigation/disclosure separation, keyboard access, disabled groups, focus recovery and invalid structures. Packed consumers verify imports, declarations, SSR and CSS with pnpm/React 19.1 and npm/React 19.3. Browser checks cover desktop/mobile, all three modes and the Pages prefix. These checks do not claim physical-device validation.

Distribute tested versioned archives and matching SHA-256 files through GitHub Releases. The fixed-name alias has the same bytes. No npm registry publication is requested.
