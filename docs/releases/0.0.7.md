# Velrino UI 0.0.7

Add a reusable, mobile-first searchable Combobox using the existing Base UI dependency.

## Usage

Import `Combobox`, `ComboboxProps` and `ComboboxOption` from the package root or `@velrino/ui/combobox`. Continue importing the bundled `@velrino/ui/styles.css` stylesheet.

Provide `options` containing unique string values and labels, `toggleLabel` and `emptyMessage`. Use `value` with `onValueChange` for controlled selection, or `defaultValue` for uncontrolled selection. `null` represents no selection. Providing a localized `clearLabel` enables clearing. Input attributes, labels, IDs, descriptions, validation state and refs are forwarded. Use `name`, `form` and `required` for form integration; submitted values use option IDs. Free text filters options and is not submitted as a selected value.

Disabled options, keyboard navigation and a visible empty state are supported. Popups stay within enclosing Dialog/Sheet focus boundaries. Escape dismisses an open popup before the parent modal. Interaction targets start at 44px, using theme tokens without imposing application routing or storage.

The gallery adds a Combobox section in English and Portuguese. Custom dictionaries need `combobox` and `sections.combobox` entries. Existing Select behavior is unchanged.

Distribute tested versioned archives and matching checksums through GitHub Releases. No npm publication is requested.
