# Velrino UI 0.0.4

Add controlled Select and StepNavigation primitives, with live English/Portuguese examples in a 17-section gallery.

## Select

- Import `Select` and `SelectOption` from `@velrino/ui/select`, or use the package root export. Trigger and popup styling use the existing theme tokens and bundled runtime stylesheet.
- Keep the selected string in application state with `value` and `onValueChange`. An explicit `value: ''` option remains a real choice with its own label, separate from the placeholder.
- Navigate choices by keyboard and return focus to the trigger after selection or dismissal. Disabled options cannot be selected, and disabling an already open Select also blocks value changes.
- Keep a popup inside its enclosing Dialog focus boundary. The first Escape closes the popup without dismissing the parent dialog; caller-provided labels, descriptions and trigger refs remain available.

## Step navigation

- Import `StepNavigation` and `NavigationStep` from `@velrino/ui/step-navigation`, or use the package root export.
- Supply controlled `current`, `steps`, `label` and `onStepChange`. Applications retain responsibility for validation, progression, content, persistence and submission.
- Use ordinary keyboard-operable stage buttons with `aria-current="step"`, optional completion marks and optional mobile short labels that retain full accessible names. Disabled navigation blocks activation, and stage buttons do not submit enclosing forms.

## Gallery and compatibility

The English and Brazilian Portuguese gallery dictionaries and navigation include Select and StepNavigation, bringing the gallery to 17 sections. Their examples preserve caller state as users change stages or gallery views. Custom `DesignSystemCopy` dictionaries need the additional `selects` and `steps` fields.

React and React DOM remain peer dependencies supporting 19.1 through 19.x. Existing runtime exports, client boundaries and CSS import paths remain unchanged; there is no Next.js or Tailwind source-scanning requirement. Load `@velrino/ui/styles.css` once, and load the separate showcase stylesheet only when embedding the gallery.

## Release validation

The release gate runs formatting, lint, package and gallery type checks, 22 behavioral tests and the production package build. Packed-consumer checks cover granular imports, declarations, server rendering, peer resolution and CSS with pnpm/React 19.1 and npm/React 19.3. Desktop/mobile gallery and actual-consumer journeys complement these checks; viewport emulation does not establish physical-device performance. Publication and CI completion are verified separately from these validation requirements.

Install the versioned `velrino-ui-0.0.4.tgz` archive and verify its adjacent SHA-256 checksum. The fixed `velrino-ui.tgz` alias contains the same package bytes. See [v0.0.4 adoption](https://github.com/velrino/velrino-ui/blob/v0.0.4/docs/adoption.md) for immutable installation and lockfile updates. Distribution remains through GitHub Releases, with no npm registry publication.
